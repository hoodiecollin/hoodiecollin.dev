This site got a full rebuild. The old version was a CMS-backed starter I never
touched; the new one is a static, MDX-driven personal site with a design system
I actually own.

## The stack

Everything compiles to a static export — no server at runtime.

- **Next.js 16** (app router) + **React 19**
- **Tailwind v4**, CSS-first, with an oklch token system
- **shadcn/ui** primitives (`radix-nova`)
- **MDX** posts compiled at build time, highlighted by Shiki
- A client-side **⌘K** palette over a prebuilt search index

## Code blocks

Fenced code is highlighted at build time with a dual light/dark theme:

```ts
export function greet(name: string): string {
  return `Hello, ${name}`;
}
```

<Callout type="tip" title="Try it">
  Hit <code>⌘K</code> to search, or toggle the theme in the header — the green
  accent stays consistent across both.
</Callout>
